# 古戈尔机 · Googol Machine

> 一款以「数学大数」为主题的增量游戏（idle / incremental game）。
> 从 <code>n+1</code> 开始，用加法、乘法、幂次、迭代幂次、箭头记号一步步往上推，
> 一路经过 **古戈尔 → 古戈尔普勒克斯 → 斯奎斯数 → 葛立恒数 → TREE(3) → SSCG(3) → 忙碌海狸 BB(n) → Rayo 数**，
> 直到语言本身失效的地方。

## 运行

纯静态、零依赖、零构建。任选一种：

    # 方式一：直接双击 googol-idle/index.html （file:// 也能跑）
    # 方式二：起一个本地服务器（推荐，存档更稳）
    cd googol-idle && python3 -m http.server 8080
    # 然后打开 http://127.0.0.1:8080/

存档自动写入浏览器 localStorage（每 15 秒一次），支持导出 / 导入文本存档，离线最多结算 12 小时（85% 效率）。

## 玩法结构

| 层级 | 名称 | 货币 | 作用 |
|---|---|---|---|
| 0 | **八层算子** | 数值 N | 主生产链：第 k 层生产第 k−1 层，第 1 层生产数值 |
| 0.5 | **跃迁** | — | 重置算子，解锁更高层 / 获得全局乘数 |
| 1 | **归零**（转生一） | 古戈尔点 GP | 门槛 10<sup>100</sup>；GP 商店 + 无限阶梯 |
| 2 | **幂塔** | 塔高 h | 数值变成 10↑↑h，用超对数 slog 度量 |
| 3 | **坍缩**（转生二） | 超越点 TP | 推倒整座塔换 TP，TP 加速塔的生长 |
| 4 | **超限阶** | 序数 α | 15 级序数阶梯：ω → ω+1 → ε₀ → Γ₀ → SVO → ω₁^CK → Rayo |
| 旁 | **关卡** | 难度系数 | 10 个带特殊规则的挑战，各 10 级，奖励 10^(难度×等级^1.2) |
| 旁 | **技能树** | 技能点 SP | 算术 / 代数 / 超越 / 元数学 四分支 24 个节点 |
| 旁 | **大数百科** | — | 27 条真实 googology 词条，每条 +1 SP 且全局 ×1.6 |

### 一条完整的正反馈链

    算子产出 → 数值 N 的数量级 L
        ├─→ 归零：GP = (L/100)²        → 全局乘数
        ├─→ 塔速率 ∝ 1 + log₁₀(1+L)/3  → 塔高 h
    塔高 h
        ├─→ 全局乘数 ×10^(2·h^0.6)     → 反哺 L
        ├─→ 总数值 = N × 10↑↑h         → 解锁大数百科
        └─→ 坍缩：TP = (h−2)²          → 塔速率、超限阶
    超限阶 → 塔速率 ×1.75 / 阶，全局 ×10⁶ / 阶，+2 SP

每一层都被下一层温和地反哺，指数被压成对数（<code>log₁₀(1+L)</code>、<code>h^0.6</code>、<code>TP^0.06</code>），
因此塔高的增长是 <code>h ∝ t^{1.1}</code> 级的多项式而不是爆炸，整条超限阶梯的节奏是**每阶耗时约 ×1.2~1.4 递增**。

## 数值设计要点

* **算子成本**：<code>cost = base · growth^bought</code>，八层 base = 10 … 10²⁴，growth = 2 … 32；
  每买 10 个该层乘数翻倍，于是「乘数 ≈ 成本^0.1」，靠单层堆量收益递减，必须靠跃迁与转生。
* **买最大**用等比数列求和精确扣费，成本指数受 <code>costPow</code>（研究 / 技能 / 关卡规则）调制。
* **关卡目标**：<code>10^(baseExp · (1.5+0.05·难度)^(等级−1))</code>，难度系数只放大 base 与奖励，
  不放大增长率，避免高难度关卡在中期变成数学上不可能。
* **超限阶需求**：塔高约 ×4 递增（10 → 40 → … → 10¹⁰），花费 TP ≈ 需求²/2.5，
  刚好等于「在该高度坍缩一次」的收益，于是每一阶天然需要「爬一次 + 坍一次」。
* **离线**：分 300 步积分，防止大 dt 让链式产出失真。

## 大数是怎么表示的

<code>src/bignum.js</code> 实现了分层大数（layered number）：

    value = sign · 10↑↑layer(mag)      // layer=0 普通数，layer=1 即 10^mag，layer=2 即 10^10^mag …

归一化不变量：<code>layer>0 时 mag ∈ [15.95, 9.007e15]</code>。
可精确表示到约 <code>10↑↑10³⁰⁸</code>，覆盖从 1 到「高度为一亿亿…的幂塔」的全部区间，
再往上（葛立恒数、TREE(3)、BB(n)）任何具体表示都是徒劳的——游戏改用**快速增长层级的序数下标**来度量，
这也是数学上真正用来比较这些数的方法。

显示记号会随规模自动切换：<code>1,234</code> → <code>1.23e45</code> → <code>e1.23e45</code> → <code>10^^1.23e6</code>。

## 界面特性

* **推导预览**：顶栏常驻一条公式条 —— <code>产出 = A₁ · 2^(b₁/10) · T₁ · G ⇒ 5.0e96 /秒</code>、
  <code>N总 = N × 10↑↑h</code>；「算子」页的**乘数推导**卡把全局乘数 G 拆成
  <code>研究 · 跃迁 2.6^37 · (1+GP)^0.5 · 1.6^百科 · 10^(2·h^0.6) · 10^(6θ) · 关卡 · 阶梯</code>
  并逐项列出各自贡献了多少倍，随时看清「这个数是怎么被算出来的」。
* **悬浮示意动画**（左下角面板，单色工业线条极简风）：指针停在哪就演示哪一种计数原理——
  后继子＝数轴逐格前进、乘法子＝**面积网格**、幂次子＝整块复制三份、迭代子＝**幂塔逐层升高**、
  箭头子＝上一行的值变成下一行的箭头数、序数＝竖线密度阶梯；
  百科条目各自绑定场景：古戈尔＝100 个零 + 与宇宙原子数的对数标尺、古戈尔普勒克斯＝写不完的零、
  葛立恒数＝ g₁→g₆₄ 的递归、TREE(3)＝不可互相嵌入的树列、忙碌海狸＝图灵机纸带与 HALT、Rayo＝可定义性的边界。
  **时间完全可控**：暂停 / +0.1 步进 / 0.25×~4× 变速 / 拖动进度条；不用时自动隐藏，可 📍 钉住。
* **渲染方式**：界面用 DOM morph 增量更新（只改变化的节点），因此按钮在每秒 10 次刷新下
  **不会闪烁、不会丢点击**——早期版本整块重建 innerHTML 会让指针下的节点被替换，
  导致 <code>:hover</code> 抖动且 mousedown / mouseup 落在不同节点。
