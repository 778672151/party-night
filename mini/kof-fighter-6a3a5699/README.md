# 烈焰对决 · KOF-STYLE FIGHTER

一个纯 `HTML + Canvas 2D + JavaScript` 手写的**拳皇（KOF）风格 2D 格斗游戏**，无任何外部素材、无需构建、无需联网：
所有人物、舞台、特效、音效、BGM 都是运行时程序化生成的。

设计的两个核心目标：

1. **打击感**（顿帧、震屏、火花、慢镜、镜头冲击、白闪、抖动、音效分层、手柄震动）；
2. **效果与判定范围严格对应**（攻击框/受击框全部由骨骼关节派生，火花生成在两框真实交点上，可用 `F1` 实时查看）。

---

## 一、运行方式

直接双击打开即可（无需服务器、无需 npm）：

```
kof-fighter/index.html
```

> 浏览器策略要求“用户操作后才能播放声音”，所以在标题画面按一次 **Enter** 之后音效/BGM 才会启动。
> 如需本地服务器：`cd kof-fighter && python3 -m http.server 8000` 然后访问 `http://localhost:8000`。

## 二、操作

| 功能 | 1P | 2P |
|---|---|---|
| 移动 / 蹲 / 跳 | `W A S D` | `↑ ← ↓ →` |
| 轻拳 A | `J` | `Num1`（或 `,`） |
| 轻脚 B | `K` | `Num2`（或 `.`） |
| 重拳 C | `U` | `Num4`（或 `;`） |
| 重脚 D | `I` | `Num5`（或 `'`） |

- 手柄（Gamepad）自动识别：左摇杆/十字键移动，`X A B Y` 对应 `A B C D`，命中时有震动反馈。
- 全局：`Enter` 确定 · `Esc` 返回 · `P` 暂停 · `R` 重开 · `M` 音乐开关 · **`F1` 判定框** · **`F2` 帧数据**

### 系统技（KOF 味）

| 指令 | 招式 | 说明 |
|---|---|---|
| `←`（后退方向） | 防御 | 站防挡中/上段，蹲防（`↙`）挡下段，**跳跃攻击必须站防** |
| `A + B` | 紧急回避（翻滚） | 第 3～20 帧全无敌，可穿过对手 |
| `C + D` | 吹飞攻击 | 大幅击退，撞墙额外演出与伤害硬直 |
| 贴身 `→/←` + `C` | 投技 | 不可防御，106 伤害 + 落地重击 |
| 双击 `→` / `←` | 前冲刺 / 后跳 | 后跳带 7 帧无敌，冲刺可直接接招 |
| 轻攻击 → 重攻击 → 必杀 → 超必杀 | 连段取消 | 轻技可互接（同招不可重复），重技命中后可必杀取消，必杀命中后可超必杀取消 |

### 角色与必杀技（4 名）

| 角色 | 必杀技 | 指令 | 超必杀（消耗 1 气） |
|---|---|---|---|
| **凯**（烈焰拳士） | 暗拂・突进拳 / 荒咬・升焰 / 九十九式 | `↓↘→`+拳 / `→↓↘`+拳 / `↓↙←`+脚 | 无式・炎之乱舞 `↓↘→↓↘→`+拳 |
| **雷克斯**（狼牙拳王） | 能量波动（弹幕） / 升龙铁拳 / 燃烧铁拳 | `↓↘→`+拳 / `→↓↘`+拳 / `↓↙←`+拳 | 猛虎硬派・波动拳 |
| **琳**（疾影舞姬） | 花蝶扇（弹幕） / 龙炎舞 / 飞鼠疾走（下段滑铲） | `↓↘→`+拳 / `→↓↘`+脚 / `↓↘→`+脚 | 忍蜂乱舞 |
| **刚**（铁山巨拳） | 地狱落（命令投・不可防） / 铁山冲 / 巨岩升踢 | `→↓↙←`+拳 / `↓↘→`+拳 / `→↓↘`+脚 | 究极・铁山乱舞 |

模式：**单人挑战（4 档 AI 难度）** / **双人对战** / **训练模式**（血气自动回满，默认可开判定框与帧数据）。

## 三、打击感是怎么做出来的

命中的那一瞬间，同时触发下面这些东西（`js/fighter.js: takeHit` + `js/fx.js`）：

| 手法 | 实现 | 数值（重拳为例） |
|---|---|---|
| **顿帧 Hitstop** | 攻守双方同时冻结动画与物理，输入仍被缓冲 | 12 帧（轻 5 / 中 8 / 反击 +5 / 超杀终结 24） |
| **受击抖动** | 被击方骨骼整体按正弦左右颤动（连判定框一起动，绝不作弊） | 振幅 4.9px，持续 顿帧+4 |
| **白闪** | 整具骨骼以纯白重绘 | 3～8 帧，按攻击等级 |
| **命中火花** | 中心辉光 + 十字星 + 冲击环 + 碎片 + 速度线，**大小随判定半径缩放** | 34 个粒子/次 |
| **屏幕震动** | 带方向（沿击退方向）的二次衰减震动 | 幅度 9～22px |
| **慢镜** | 主循环按比例跳过逻辑帧（不是降帧率） | 重击 6 帧 ×0.3 速，终结技 20 帧 ×0.2 |
| **镜头冲击** | 命中瞬间推近再回弹 | +2%～16% |
| **挥击轨迹** | 把**每一帧真实的攻击判定胶囊**画成渐隐光带 | 出招期间逐帧记录 |
| **音效分层** | 噪声爆(高频撕裂) + 低频正弦(体感闷响) + 短方波(点击感)，全部 WebAudio 实时合成 | 24 种音效 + 程序化 BGM |
| **手柄震动** | `vibrationActuator` 按等级给强度 | 0.3～1.0 |
| **其它** | 伤害数字、连击数、COUNTER / TRADE / WALL! / GUARD CRUSH 提示、撞墙演出、超必杀全屏压暗+光条+角色台词、KO 慢镜与镜头拉近 | |

## 四、“效果对应范围准确”是怎么保证的

这是本项目的**架构级**保证，而不是靠手调贴图：

1. **骨骼驱动**：角色不是精灵图，而是 11 个关节的骨架（`js/rig.js`）；招式帧数据只描述关节位置的关键帧（`js/moves.js`），运行时插值。
2. **判定框由同一套关节派生**：
   - 攻击判定 = `hitCapsule(J, {from:'eF', to:'hF', r, ext})` —— 就是**画出来的那条前臂/小腿本体**加半径；
   - 受击判定 = `hurtboxes(J)` —— 头/躯干/四肢各自的胶囊，蹲下、后仰、浮空时自动跟着骨骼变形；
   - 出招时**攻击中的那条肢体不带受击框**（`skip`），因此才有真实的对拼（TRADE）。
3. **胶囊-胶囊碰撞**求最近点对，命中点按两者半径加权取在“表面之间”，火花就生成在这个点上 —— 所见即所中。
4. **`F1` 判定框视图**：红=攻击框、蓝=受击框、绿=推挤框、黄十字=最近若干次真实命中点、底部标尺显示两人实时距离；`F2` 显示当前招式的发生/持续/收招帧、顿帧、无敌帧、浮空数。

自动化验证（见下）实测：**命中点到攻击胶囊/受击胶囊的距离偏差 0.00px（100% 落在两框交集内）**，
**屏幕火花亮度重心与理论命中点相差 2～14px**，**攻击框顶端超出可视肢体 6～13px**（格斗游戏常规的“判定略大于视觉”，且已收紧过）。

## 五、文件结构

```
kof-fighter/
├─ index.html          页面与脚本装载（普通 <script>，可直接 file:// 打开）
├─ css/style.css       16:9 letterbox、扫描线、提示条
└─ js/
   ├─ core.js          数学/几何（线段最近点、胶囊碰撞）+ 输入（键盘/手柄/指令输入识别）
   ├─ audio.js         WebAudio 程序化音效 24 种 + 16 分音符调度的 BGM
   ├─ rig.js           骨骼、姿势库、关键帧插值、由骨骼派生判定框、卡通描边绘制
   ├─ fx.js            火花/冲击环/碎片/速度线/烟尘/火焰/残影/轨迹/伤害数字/震屏/慢镜/镜头冲击
   ├─ moves.js         全部帧数据：普通技 11 招 + 系统技 3 招 + 6 种必杀原型 + 乱舞超必杀生成器
   ├─ chars.js         4 名角色的配色、数值、必杀技组合
   ├─ fighter.js       状态机：移动/跳跃/冲刺/防御/受身/浮空/投技/连段取消/气槽/防御崩坏
   ├─ ai.js            CPU：距离决策 + 反应延迟 + 防御/对空/反击/连段/超杀，4 档难度
   ├─ stage.js         3 套程序化舞台（视差楼群、灯窗、观众、灯笼、暗角）
   ├─ hud.js           KOF 风格斜切血条（含受伤残影）、气槽、防御槽、连击数、计时器、菜单、调试面板
   ├─ game.js          主循环（固定 60Hz + 慢镜）、命中结算、推挤、撞墙、回合流程、摄像机
   └─ main.js          启动
```

## 七、已知取舍

- 贴身按 `→ + C` 会优先出投技（KOF 传统设定），想出重拳请在稍远距离或不按方向。
- 空中不能防御（与 KOF 一致）。
- 人物为程序化骨骼卡通渲染，追求的是动作辨识度与判定一致性，不是像素点绘。
